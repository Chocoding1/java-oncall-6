# 미션 - 개발자 비상근무

# 구현 기능 목록
1. [입력] 비상 근무 배정 월과 시작 요일을 입력받는다.
   - [예외 처리] 공백을 입력할 경우 에러 메시지를 출력하고 재입력받는다.
   - [예외 처리] 월이 1 ~ 12 사이의 숫자가 아닌 경우 에러 메시지를 출력하고 재입력받는다.
   - [예외 처리] 요일이 월 ~ 일에 포함되지 않을 경우 에러 메시지를 출력하고 재입력받는다.

2. [입력] 평일 비상 근무 순번대로 사원 닉네임을 입력받는다.
   - [예외 처리] 닉네임이 공백이거나 5자를 초과할 경우 에러 메시지를 출력하고 재입력받는다.
   - [예외 처리] 중복된 닉네임이 존재할 경우 에러 메시지를 출력하고 재입력받는다.
   - [예외 처리] 비상 근무자의 수가 35명을 초과할 경우 에러 메시지를 출력하고 재입력받는다.

3. [입력] 휴일 비상 근무 순번대로 사원 닉네임을 입력받는다.
   - [예외 처리] 닉네임이 공백이거나 5자를 초과할 경우 에러 메시지를 출력하고 평일 비상 근무자부터 재입력받는다.
   - [예외 처리] 중복된 닉네임이 존재할 경우 에러 메시지를 출력하고 평일 비상 근무자부터 재입력받는다.
   - [예외 처리] 비상 근무자의 수가 35명을 초과할 경우 에러 메시지를 출력하고 평일 비상 근무자부터 재입력받는다.

4. [중간 과정] 비상 근무표를 생성한다.

5. [출력] 비상 근무표를 출력한다.
